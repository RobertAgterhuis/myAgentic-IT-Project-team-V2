# Artifact Browser Overview

Artifacts capture outputs produced by agents across phases.

## Artifact types

Common examples include reports, plans, checklists, and generated implementation outputs.

## Lineage view

Use lineage to understand dependencies and sequence between outputs.

## Export and evidence

Export artifacts when you need compliance evidence or external review packages.
