# Command Prerequisites

Before running commands, confirm these prerequisites.

## Repository readiness

- The repository is cloned and you are on the intended branch.
- Required instruction files are present and up to date.
- Workspace has no unexpected or conflicting local changes.

## Environment readiness

- Node.js and npm versions are compatible with the project.
- Dependencies are installed.
- Required environment variables and secrets are configured.

## Process readiness

- The target issue or scope item is defined.
- Any needed approvals are identified in advance.
- Success criteria and acceptance checks are clear.

## Validation readiness

- Test commands are available and passing locally.
- Lint/format tooling is available.
- You can run build and quality gates before merge.
