# Execution History Guide

Execution History is where you confirm whether a failure is isolated, recurring, or getting worse over time.

## What this page is for

Use this page when current agent status is not enough and you need historical evidence.

## What to do here

1. Filter by agent, time range, and status.
2. Compare retry patterns across similar failures.
3. Look for repeated provider, model, or contract issues.
4. Use that evidence before changing prompts, policies, or permissions.

## Why this matters

Changes made without historical evidence often fix the wrong layer. This page helps you justify whether the remedy belongs in runtime config, prompts, inputs, or governance.
