# Prompt & Contract Registry Guide

The Prompt & Contract Registry explains the rules that agent runs are expected to follow.

## What this page is for

Use this page before changing prompt assets or when diagnosing behavior that seems inconsistent with expectations.

## What to do here

1. Review the prompt or contract that governs the workflow.
2. Confirm expected input and output structure.
3. Compare the contract with the actual failure or weak output you observed.

## Why this matters

Many execution problems look like runtime issues but are actually caused by weak prompt boundaries or misunderstood output contracts.
