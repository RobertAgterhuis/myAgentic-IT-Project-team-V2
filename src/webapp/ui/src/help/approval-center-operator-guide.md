# Approval Center Guide

Approval Center exists for the cases where automation must stop and a human must decide.

## What this page is for

Use this page to review requests that have governance, risk, or compliance implications.

## What to do here

1. Read the request and linked evidence.
2. Confirm whether the risk is understood.
3. Approve or reject with a clear explanation.
4. Use overrides only when an exception is justified and documented.

## Why this matters

Approval quality determines whether the system stays governed. A fast decision without rationale is only slightly better than no decision.
