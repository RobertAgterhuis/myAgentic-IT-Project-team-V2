# Hotfix Bypass

Hotfix bypass is an emergency mechanism, not a normal delivery path.

## When it may apply

- Active incidents that require immediate mitigation.
- Urgent reliability or security regressions that cannot wait for a full cycle.

## Required controls

- Explicit emergency justification.
- Named accountable approver.
- Time-bounded scope limited to mitigation.
- Mandatory post-incident retrospective and reconciliation.

## After-action requirements

Any bypassed checks must be completed retrospectively, with findings linked to the relevant issue and governance records.
