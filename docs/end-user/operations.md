# User Operations Guide

## Core Workflow Modes

- `CREATE`: Start a new initiative.
- `FEATURE`: Deliver scoped improvements.
- `AUDIT`: Validate state and compliance.
- `REEVALUATE`: Reassess based on new evidence.

## Best Practices

- Review gate outputs before approving progression.
- Keep requirements explicit and testable.
- Use generated artifacts for release reviews.

## Safety Model

The platform is intended for supervised operation with human approvals on critical transitions.
