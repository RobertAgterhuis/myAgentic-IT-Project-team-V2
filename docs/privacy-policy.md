# Privacy Policy — Agentic SDLC Platform

**Effective Date:** 2026-03-12  
**Version:** 1.0  
**Last Updated:** 2026-03-12

---

## 1. Introduction

The Agentic SDLC Platform is a locally-hosted software development lifecycle
management tool. This privacy policy describes how data is handled when you use
the platform.

**Key principle:** In the default configuration (v1 GA), all data stays on your
local machine. No data is transmitted to external servers by the platform
itself.

---

## 2. What Data We Process

### 2.1 Data You Provide

- **Questionnaire answers** — Business context and project requirements you
  enter through the web interface
- **Decision records** — Choices and rationale you document during the project
  lifecycle
- **Configuration** — Environment variables and settings in `.env` files

### 2.2 Data Generated During Use

- **Session state** — Current project phase, sprint progress, and agent status
  (stored as JSON files)
- **Deliverables** — Analysis documents, plans, and reports generated by the
  multi-agent system (stored as Markdown files)
- **Git commit metadata** — Your name and email address as configured in Git
- **Server logs** — Request logs printed to the terminal (not persisted to disk)

### 2.3 Optional: Analytics Data

If you enable Matomo analytics (via Docker):

- **Page views and navigation** — Which pages you visit in the web interface
- **Browser metadata** — User-Agent, screen resolution, language preference

Matomo runs locally in a Docker container. Analytics data is stored in a local
MariaDB database and is not transmitted externally.

---

## 3. Where Data Is Stored

| Data Type     | Storage Location                                  |
| ------------- | ------------------------------------------------- |
| Project files | Your local file system (project directory)        |
| Session state | `.github/docs/session/` (JSON files)              |
| Business data | `BusinessDocs/` (Markdown files)                  |
| Analytics     | Docker volume on your machine (if Matomo enabled) |
| Git history   | `.git/` directory                                 |

**No cloud storage, no external databases, no remote APIs** are used by the
platform in its default configuration.

---

## 4. Data Sharing

The platform does not share your data with any third party. Specifically:

- No telemetry is collected or transmitted
- No analytics data leaves your machine
- No API calls to external services are made by the platform
- GitHub integration (if used) only creates issues/PRs that you explicitly
  trigger — content is under your control

**Note:** Your AI coding assistant (e.g., GitHub Copilot) operates under its own
privacy policy. The platform does not control what context your AI assistant
sends or receives.

---

## 5. Your Rights

You have full control over all data processed by the platform:

### 5.1 Access

All data is stored in human-readable formats (Markdown, JSON) that you can
inspect directly. See `.github/docs/data-inventory.md` for a complete catalog.

### 5.2 Export

Copy the project directory to export all data. For analytics data, use Matomo's
built-in GDPR export feature.

### 5.3 Deletion

- Delete the project directory to remove all project data
- Run `docker-compose down -v` to remove analytics data
- See `.github/docs/data-inventory.md` Section 3, "Data Deletion" for detailed
  procedures

### 5.4 Rectification

Edit any Markdown or JSON file directly to correct inaccurate data.

---

## 6. Security

See `.github/docs/security-design.md` for the complete security design. Key
measures include:

- Content Security Policy (CSP) headers
- Path traversal prevention
- Input sanitization
- Secret detection in commits
- File-level locking for concurrent access safety

---

## 7. Children's Privacy

The platform is a software development tool not directed at children under 13.
We do not knowingly process data from minors.
