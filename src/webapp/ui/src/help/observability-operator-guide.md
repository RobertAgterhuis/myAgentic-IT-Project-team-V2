# Observability Operator Guide

Observability is where you confirm whether a signal is real, what changed, and which evidence supports that conclusion.

## What this page is for

Use this page when summary indicators are not enough and you need evidence across multiple telemetry views.

## What to do here

1. Use Drift & KPIs to spot change.
2. Use Analytics & Velocity to see whether the issue is directional or temporary.
3. Use Traceability and Diff Review to explain what changed.
4. Use Alerts and Streams to confirm whether the signal is active now.

## Why this matters

A single chart rarely explains a workflow issue. This page matters because it brings multiple evidence types into one workspace.
