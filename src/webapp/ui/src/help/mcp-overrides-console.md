# Override Console Guide

Overrides are for temporary exceptions. They are not the normal way to manage permissions.

## What to do here

1. Review existing overrides before creating a new one.
2. Document why the exception is needed.
3. Remove the override when the underlying issue is fixed.

## Why this matters

Unmanaged overrides quietly become permanent policy drift. This page helps prevent that.
