# Agent Permission Matrix Guide

The permission matrix shows what each agent is allowed to do through MCP-connected tools.

## What to do here

1. Find the agent you are reviewing.
2. Check the exact tools and capabilities it can invoke.
3. Compare that access to the work the agent is actually supposed to perform.

## Why this matters

The safest permission model is the narrowest one that still allows the workflow to succeed.
