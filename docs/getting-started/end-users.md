# End-User Quick Start

## What You Can Do

- Trigger governed SDLC flows.
- Track progress and decisions.
- Review generated artifacts and evidence.

## Start the Platform

```bash
npm ci
npm ci --prefix src/webapp/ui
npm start
```

Open: `http://127.0.0.1:3000`

## Typical Usage

1. Open the web app.
2. Select a workflow mode (for example CREATE or FEATURE).
3. Review outputs at each gate.
4. Approve or request changes.

See also: [User Operations Guide](../end-user/operations.md)
