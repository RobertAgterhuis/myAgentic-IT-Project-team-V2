# User Test Suite

This folder contains a structured test pack for someone who clones this repository from GitHub and wants to validate that the solution is usable for their own project.

Use the files in this order:

## How To Use This Test Pack

- Run the scenarios in order for a full end-to-end evaluation.
- If time is limited, run files 01, 02, 03, and 09 first.
- Record findings directly in each file under the feedback sections.
- If a step fails, note the exact step number, what you expected, what actually happened, and whether the failure blocks adoption.

| Rating          | Meaning                                             |
| --------------- | --------------------------------------------------- |

| Pass with notes | Worked, but friction or confusion exists            |
| Partial         | Some parts worked, but the scenario is not reliable |
| Fail            | Core expected outcome did not happen                |
