# Lineage Explorer Guide

Lineage shows how artifacts relate to one another across the workflow.

## What this page is for

Use Lineage Explorer when you need to know where an output came from or what else will be affected if it changes.

## What to do here

1. Start from the artifact you care about.
2. Trace backward to the questions, decisions, prompts, or prior artifacts that shaped it.
3. Trace forward to see what later outputs depend on it.

## Why this matters

Without lineage, operators change inputs blindly and only discover downstream damage later. With lineage, you can estimate impact before acting.
