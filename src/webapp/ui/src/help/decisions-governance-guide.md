# Decisions & Governance Guide

The Decisions page is where ambiguity becomes explicit and where important choices become durable context.

## What this page is for

Use Decisions to manage open questions, approved outcomes, deferred items, and governance context that agents should not invent.

## What to do here

1. Create open questions when progress depends on a human answer.
2. Record decided outcomes with rationale, not just a short label.
3. Keep deferred items visible so temporary choices do not become hidden defaults.

## Why this matters

Undocumented decisions create repeated confusion. Documented decisions reduce rework, duplicate questions, and policy drift.

## Good operator habit

If a future run should inherit a choice, capture it here. If the choice is still provisional, mark it as such.
