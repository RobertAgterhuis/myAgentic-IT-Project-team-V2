# MCP Agent Inspector Guide

Agent Inspector is for detailed, per-agent review.

## What to do here

1. Open the specific agent you are investigating.
2. Review its effective MCP capabilities and boundaries.
3. Compare expected behavior to actual access.

## Why this matters

When one agent behaves unexpectedly, broad permission changes are usually the wrong response. Inspect the specific agent first.
