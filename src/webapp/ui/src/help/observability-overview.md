# Observability Tabs Explained

Each tab answers a different question.

## Drift & KPIs

Use this tab when you want to know whether behavior or output quality is changing.

## Analytics & Velocity

Use this tab when you want to understand trend direction, throughput, and operational momentum.

## Traceability

Use this tab when you need evidence about where an outcome came from.

## Diff Review

Use this tab when you need a before-versus-after explanation rather than a single snapshot.

## Alerts

Use this tab when you need active operational issues to triage.

## Telemetry Streams

Use this tab when you want rawer signal context behind summarized alerting.
