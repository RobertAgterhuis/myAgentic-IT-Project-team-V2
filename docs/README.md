# Platform Overview

myAgentic-IT is a governed SDLC orchestration platform.

## What It Is

- A control plane for CREATE, AUDIT, FEATURE, REEVALUATE, and related workflows.
- A platform that enforces gate checks, traceability, and policy guardrails.
- A system designed for human-in-the-loop delivery confidence.

## What It Is Not

- A fully unattended software delivery autopilot.

## Stack

- Backend: Fastify + TypeScript
- Frontend: React/Vite
- Runtime baseline: Node.js 22+
