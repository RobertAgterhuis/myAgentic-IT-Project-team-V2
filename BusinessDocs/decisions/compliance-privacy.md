# Decisions: Compliance & Privacy

> Stack: compliance-privacy | Status: ACTIVE | Applicable: YES
>
> Created 2026-03-16. Best-practice decisions for GDPR/CCPA compliance, consent
> management, data subject rights, data retention, cookie governance, and
> privacy-by-design for full-stack applications.

---

## Decided Items

| ID      | Priority | Scope                                    | Decision                                                                                                                                                                                                                                                                                                                                                                                                             | Notes | Date       |
| ------- | -------- | ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- | ---------- |
| DEC-481 | HIGH     | All Phases (Privacy Regulation Baseline) | Design for GDPR compliance as the baseline (strictest common denominator). Layer CCPA/CPRA requirements for US users where applicable. Conduct a Data Protection Impact Assessment (DPIA) before processing sensitive personal data. Maintain a Record of Processing Activities (ROPA). Appoint a data protection contact and document the privacy governance structure.                                             |       | 2026-03-16 |
| DEC-482 | HIGH     | Phase 2 (Consent Management)             | Implement a Consent Management Platform (CMP) that: collects explicit opt-in consent before processing personal data, records consent with timestamp/version/scope, allows users to modify or withdraw consent at any time, and provides consent audit trail. No pre-checked consent boxes. Consent must be granular (per purpose), not bundled.                                                                     |       | 2026-03-16 |
| DEC-483 | HIGH     | Phase 2 (Data Subject Rights)            | Implement automated or semi-automated support for: Right of Access (export user data in machine-readable format), Right to Rectification (user can correct their data), Right to Erasure (delete personal data on request, within 30 days), Right to Portability (export in JSON/CSV), Right to Restrict Processing. Track and audit all data subject requests. Respond within regulatory deadlines (30 days GDPR).  |       | 2026-03-16 |
| DEC-484 | HIGH     | Phase 2 (Data Retention)                 | Define retention periods per data category: user accounts (duration of relationship + 30 days), transaction records (per financial regulation, typically 7 years), logs (90 days operational, 1 year audit), analytics (aggregated: indefinite, raw: 13 months max). Implement automated deletion/anonymization when retention period expires. Document retention schedule and review annually.                      |       | 2026-03-16 |
| DEC-485 | HIGH     | Phase 2 (Data Minimization)              | Collect only personal data that is strictly necessary for the stated purpose. Review data collection at every new feature — challenge every field. Anonymize or pseudonymize personal data wherever possible (especially for analytics, testing, and development). Delete or aggregate personal data as soon as the original purpose is fulfilled. No "collect now, figure out later" approach.                      |       | 2026-03-16 |
| DEC-486 | HIGH     | Phase 3 (Cookie Policy)                  | Classify cookies: strictly necessary (no consent needed), functional, analytics, and marketing. Obtain consent before setting non-essential cookies. Provide a cookie banner/preference center compliant with ePrivacy Directive and GDPR. Document all cookies: name, purpose, duration, provider, and category. Review cookie inventory quarterly. Respect Do Not Track (DNT) header as an additional signal.      |       | 2026-03-16 |
| DEC-487 | MEDIUM   | Phase 2 (Privacy by Design)              | Encrypt personal data at rest and in transit. Use pseudonymization (replace identifiers with tokens) where possible. Implement access controls so only authorized roles can access personal data. Log all access to personal data for audit. Design data flows to minimize cross-border transfers. Where cross-border transfers are necessary, ensure adequate safeguards (SCCs, adequacy decisions).                |       | 2026-03-16 |
| DEC-488 | MEDIUM   | Phase 2 (Breach Notification)            | Implement a breach response plan: detect breach → assess severity → notify supervisory authority within 72 hours (GDPR) → notify affected individuals if high risk. Maintain a breach register. Conduct breach simulation exercises annually. Include breach detection in monitoring (DEC-420) — alert on anomalous data access patterns.                                                                            |       | 2026-03-16 |
| DEC-489 | MEDIUM   | Phase 3 (Privacy UX)                     | Provide a privacy center/dashboard where users can: view their data, manage consent preferences, download their data, and request deletion. Privacy policy must be written in clear language (not legal jargon). Display privacy information contextually (why is this data collected — at the point of collection). Respect user privacy preferences immediately — no "takes up to 30 days" for consent withdrawal. |       | 2026-03-16 |
| DEC-490 | LOW      | Phase 2 (Third-Party Data Sharing)       | Maintain a register of all third-party data processors. Data Processing Agreements (DPAs) must be in place before sharing personal data. Share only the minimum data required per purpose. Audit third-party data handling annually. Provide users with transparency about which third parties receive their data. Review and update third-party agreements when regulations change.                                 |       | 2026-03-16 |
