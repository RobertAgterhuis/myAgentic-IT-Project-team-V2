# Handoff Examples

This folder contains validated examples that use the unified handoff template.
Each example is annotated to explain why optional sections are included or
omitted.

Coverage goals:

- At least 10 examples
- Multiple domains (business, architecture, engineering, UX, compliance)
- Multiple outcomes (COMPLETED, BLOCKED, ESCALATED)
