# Cockpit Overview

Cockpit provides live operational awareness for ongoing execution.

## Telemetry and stream signals

Monitor event flow, execution state, and health indicators in near real time.

## Alert-driven intervention

Prioritize unresolved approvals and execution failures that can block progress.

## Drill-down workflow

Jump from cockpit cards to detailed pages for diagnosis and remediation.
