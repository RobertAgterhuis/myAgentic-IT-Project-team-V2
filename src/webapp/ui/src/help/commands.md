# Commands Reference

Use this page to choose the right command mode before execution starts.

## When to use each mode

- CREATE: Start a full delivery cycle from a new brief.
- AUDIT: Analyze an existing implementation before changing it.
- FEATURE: Deliver a scoped enhancement on an existing product.
- HOTFIX: Handle urgent production issues with minimal path length.

## Inputs that improve outcomes

Provide a clear project name, scope, and expected outcome. Better input quality improves downstream agent decisions.

## What happens next

After queueing, track execution in Pipeline and Sessions.
