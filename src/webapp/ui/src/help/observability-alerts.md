# Alert Triage Guide

Alerts should change behavior only when they are understood.

## What to do first

1. Confirm severity and recency.
2. Identify the source system or telemetry stream.
3. Cross-check the alert against Sessions, Pipeline, or Cockpit.

## Why this matters

Treating every alert as urgent creates alert fatigue. Ignoring alerts creates avoidable failures. Triage is how you stay in the middle.

## Good operator habit

Use alerts as starting points, not final conclusions.
