# MCP Governance Guide

MCP governance is not one page. It is a workflow across several administration views.

## Use the right page for the right question

- Use Matrix to understand broad access design.
- Use Agent Inspector to review one agent deeply.
- Use Overrides for temporary exceptions.
- Use Diagnostics to understand why a tool path is failing.

## Why this matters

Most permission mistakes happen when operators use the wrong tool for the question they are trying to answer.

## Good admin habit

Start with diagnosis, then confirm intended access, then make the narrowest possible change.
